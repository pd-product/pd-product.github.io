Schema.org type names are case-sensitive, `imageObject` is not a registered type, and `alt` is not a Schema.org property, so the hash form buys three meta tags at the cost of a malformed image node on every page. These MUST follow {% seo %}: Open Graph structured properties describe the og:image immediately preceding them, and seo-tag emits that. The equality test is load-bearing. A story may override `image` with its own card, and these dimensions would then describe a DIFFERENT file -- a wrong width is worse than an absent one, because a scraper reserves the wrong box and the card renders letterboxed or cropped. So the three tags are emitted only when the page is actually using the default card.
